# Изменения модели

Документ фиксирует расхождения между версией, представленной на защите
курсового проекта, и текущей версией.

## 1. Покрытие БПЛА вычисляется, а не постулируется

**Было.** Совокупное покрытие рассчитывалось как

    coverage_total = coverage_cameras + len(uncovered) / N * 100

то есть все непокрытые стационарными камерами точки объявлялись покрытыми
аппаратами. Показатель тождественно равнялся 100 %, как только строился хотя
бы один маршрут, и не зависел ни от числа аппаратов, ни от их дальности.

**Стало.** У мобильной подсистемы появились собственные ограничения: бюджет
флота `K_d` (`max_units` в XML), лимит длины маршрута `R_max` и радиус полосы
наблюдения `r_obs` (`obs_radius_m`). Точка считается наблюдаемой, если
расстояние от неё до ломаной маршрута не превышает `r_obs`. При недостатке
ресурсов часть точек остаётся непокрытой, и совокупное покрытие строго меньше
100 %.

Промежуточная версия правки (маршрут строится через все непокрытые точки,
число аппаратов подбирается по допустимости) была отвергнута: маршрут,
проходящий через точку, покрывает её по построению, поэтому покрытие вновь
оказывалось тождественно полным.

## 2. Обход запретных зон проверяется целиком

**Было.** В качестве точки обхода выбирался ближайший угол запретной зоны без
проверки полученного пути. На штатном примере один сегмент маршрута
продолжал пересекать игровое поле.

**Стало.** Перебираются варианты обхода через один и через два угла; вариант
принимается, только если все его плечи свободны от всех запретных зон, из
допустимых выбирается кратчайший.

## 3. Лимит длины маршрута соблюдается

**Было.** Разбивка на сегменты пропускала случаи с добавленными точками
обхода: на штатном примере строился маршрут длиной 68,7 м при лимите 50 м.

**Стало.** Звено добавляется, только если укладывается в остаток лимита.
Инвариант проверяется тестами и прогоном сценариев.

## 4. Критерий Score перестал вырождаться

**Было.** `Coverage_norm = Coverage / max(Coverage)`. Конфигурация,
максимальная одновременно по покрытию и по стоимости, всегда получала
`Score = w_cov - w_cost` (0,4 при штатных весах) независимо от показателей.

**Стало.** `Coverage_norm = Coverage / 100` — нормировка по физическому
максимуму.

## 5. ЦЛП разрешает ничьи по стоимости

**Было.** Целевая функция учитывала только покрытие; при равном покрытии
выбор позиций был произвольным.

**Стало.** Добавлен штраф `-eps * sum(c_j / c_max * x_j)` с `eps = 0.5 / K`.
Штраф строго меньше единицы и не может перевесить покрытую точку. На сценарии
«стадион» результат улучшился одновременно по покрытию (95 против 94 точек)
и по стоимости (900 000 против 910 000 руб.).

## 6. Маршрутизация стала содержательной

**Было.** Маршрут строился правилом ближайшего соседа; при радиусе полосы
наблюдения, сопоставимом с размером кластера, маршрут вырождался в точку
зависания, и алгоритмы маршрутизации фактически не работали.

**Стало.** Точка выбирается по критерию максимального прироста наблюдаемости
на единицу длины маршрута (учитывается захват попутных точек), затем порядок
обхода улучшается процедурой 2-opt, а высвободившийся ресурс дальности
расходуется на дополнительные точки. В отчётных сценариях длины маршрутов
составляют 16–46 м при полосе 3–5 м.

### 6.1. 2-opt заменён локальным поиском по правильному критерию

**Было (промежуточная версия).** После жадного наращивания применялся
классический 2-opt, минимизирующий длину маршрута. Измерение показало, что
на 15 сценариях он срабатывал 5 раз из 39 вызовов, причём в одном случае
**снизил наблюдаемость с 17 точек до 16**, сократив маршрут с 42,9 до 38,3 м.
Причина принципиальная: 2-opt оптимизирует длину тура, тогда как решаемая
подзадача — задача об ориентировании (максимум обслуженных точек при
ограничении на ресурс). Сокращение маршрута способно вывести точки из полосы
наблюдения.

**Стало.** Локальный поиск в трёх окрестностях — 2-opt (разворот участка),
Or-opt (перенос точки) и замена посещаемой точки на непосещаемую — с
лексикографическим критерием приёма: сначала наблюдаемость, затем длина.
Случаев потери наблюдаемости больше нет (проверено на всех сценариях).

Эффект на результатах: требуемый флот сократился в двух сценариях —
на стадионе при K = 8 с трёх аппаратов до двух, при K = 4 с пяти до четырёх;
на площадке при K = 1 покрытие выросло с 97,1 % до 98,6 %.

## 7. Определение состава флота

**Было.** Число аппаратов задавалось формулой по площади, размерно
некорректной (дальность маршрута трактовалась как радиус круга).

**Стало.** Реализован режим `--target-coverage`: бюджет флота наращивается от
нуля до первого значения, при котором достигается заданный уровень покрытия.
Это прямо отвечает постановке «определение состава флота».

## 8. Сравниваются только конфигурации, решающие задачу

**Было.** В ранжирование попадали варианты с покрытием ниже целевого, и
критерий рекомендовал самый дешёвый из них (например, 78,7 % при цели 95 %).

**Стало.** При заданном целевом уровне для каждой альтернативы подбирается
свой минимальный флот; не достигшие цели конфигурации исключаются из
сравнения с указанием причины.

## 9. Прочее

- Матрица покрытия вычисляется векторизованно (numpy) вместо двойного цикла.
- Точки пересекающихся зон наблюдения дедуплицируются.
- Некорректный или отсутствующий XML вызывает понятную ошибку `ValueError`.
- Добавлены описания зала и площадки (`data/hall_example.xml`,
  `data/court_example.xml`) — ранее эти объекты фигурировали только в тексте.
- Добавлены модульные тесты (46 шт.) и прогон 15 тест-сценариев.
- Рисунки строятся из модели (`tools/plot_scenario.py`), поэтому число точек
  на иллюстрации совпадает с N в тексте.
- README приведён в соответствие с фактическим выводом программы.

## Влияние на результаты

| Показатель | Прежняя версия | Текущая версия |
|---|---|---|
| Совокупное покрытие | всегда 100 % при наличии БПЛА | измеряется; 95,4–100 % в сценариях с БПЛА |
| Целевой уровень 95 % | не проверялся | достигнут во всех 13 сценариях с БПЛА, флот ≤ 4 |
| Допустимость маршрутов | не проверялась | проверяется, нарушений нет |
| Тестовое покрытие | отсутствует | 46 модульных тестов |
| Длины маршрутов | вырождались в 0 м | 9–49 м при полосе 3–5 м |
| Состав флота | задавался вручную | подбирается под целевой уровень |

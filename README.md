# sport-coverage-optimizer

Оптимизационная модель покрытия спортивного объекта устройствами видеорегистрации.

**Курсовой проект**, КубГУ, кафедра информационных технологий, 2026.

## Описание

Программный комплекс решает задачу оптимального размещения стационарных видеокамер и БПЛА
на спортивном объекте с целью максимизации покрытия при заданном бюджете.

Задача размещения камер формализована как задача целочисленного линейного программирования (ЦЛП).
Для зон, недоступных стационарным камерам, строятся маршруты БПЛА методом кластеризации (K-means)
и алгоритмом ближайшего соседа.

## Структура

```
sport-coverage-optimizer/
├── README.md
├── requirements.txt
├── main.py                        # точка входа
├── data/
│   └── stadium_example.xml        # пример описания объекта
└── src/
    ├── spatial_model.py           # геометрия, сетка, матрица покрытия
    ├── stationary_optimizer.py    # ЦЛП: оптимальное размещение камер
    ├── drone_optimizer.py         # K-means + ближайший сосед для БПЛА
    ├── economic_balancer.py       # TCO и взвешенная сумма конфигураций
    └── report_generator.py        # генерация XML-отчёта
```

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py --input data/stadium_example.xml --budget 15 --drone-range 50
```

### Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| `--input` | Путь к XML-описанию объекта | `data/stadium_example.xml` |
| `--budget` | Максимальное число стационарных камер | `12` |
| `--drone-range` | Дальность БПЛА, м | `50` |
| `--grid-step` | Шаг сетки точек наблюдения, м | `5` |
| `--output` | Путь к выходному XML-отчёту | `output_config.xml` |

## Стек технологий

- Python 3.11
- numpy — матричные операции, геометрия
- xml.etree.ElementTree — парсинг XML объекта и генерация отчёта
- scikit-learn — кластеризация K-means (опционально)
- PuLP — решатель ЦЛП (опционально, есть встроенная замена)
